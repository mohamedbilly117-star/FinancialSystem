# GovERP

A financial management system built with ASP.NET Core and Blazor.

## Overview

GovERP is a web-based financial management system designed to organize and manage financial operations and related data.

## Technology

- ASP.NET Core
- Blazor
- C#
- .NET

## Project Structure

- `src/` — Application source code
- `tests/` — Automated tests

This project is currently under active development.
